## 5. Caveats

* 100% of `distributions.access_url` values are percent-encoded as stored (raw comparison would show 0 matches).
* `distributions.access_url` includes downloads (.zip/.pdf), OGC services (WMS/WFS) and API endpoints — not only landing pages.
* `maps.bonares.de` URLs do not answer from this network (untested, not proven broken); `blocked` means bot/login-gated, likely fine in a browser.
